# Weekly review

1. `uv run dh plan show --history`: each position vs plan (stop, T1, out-by) and every plan change logged this week.
2. `uv run dh analytics`: week change and weekly trend line, latest candles, volume trend, watchlist names near their levels.
3. `uv run dh paper scorecard`: paper book vs benchmark.
4. Earnings inside holds next week: from each risk card (`uv run dh risk-card TICKER`).
5. Sentiment trend (`sentiment`: not built yet).
