# Morning brief

Combine, short and facts-only:
1. Plan status: `uv run dh plan show`.
2. Holdings vs levels: `uv run dh watch` (`level-watch`). Pre-market prices aren't in it yet; the extended-hours volume line in `dh analytics` is the only pre-market data for now.
3. Overnight material news (`news-watch`: not built yet).
4. Sentiment snapshot for holdings and the market (`sentiment`: not built yet).
5. Today's events (`calendar`: not built yet). Earnings inside a hold show on each risk card.
6. Any plan with a level, out-by date, or earnings today.

Skip any section that has nothing new. Mention unbuilt sections once, in one line.
